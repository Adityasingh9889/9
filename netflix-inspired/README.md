# StreamFlix — Android Streaming UI

A dark, cinematic Netflix-inspired Android streaming app starter.

## Included
- Home screen with hero section
- Trending catalog
- Show details dialog
- Dark streaming-style UI
- GitHub Actions workflow that builds a debug APK automatically

## Build
Push to main, then open Actions → Build Android APK. The workflow publishes the generated APK as an artifact.

This project uses original demo branding and sample titles. Add only content and media you are licensed to distribute.
